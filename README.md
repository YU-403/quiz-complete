# Quiz Complete · 出题建站一体

> **本仓库是一个 AI Agent Skill，用于导入到兼容 Claude Agent 的客户端（如 CherryStudio 等）中使用。**
> AI 会按照本 Skill 定义的工作流，全自动完成从出题到建站的全部步骤。

---

## 这个 Skill 解决什么问题

期末复习时，你大概率遇到过这样的困境：课本翻了好几遍，但手头只有老师给的几道例题，想大量刷题却没有现成的题集；自己出题吧，对着教材一行一行找考点、手打题目和选项，费时费力；想做个刷题网页，又不会写前端代码。

这个 Skill 就是为了解决这个问题而诞生的——把「出题」和「建站」合并成一条流水线，让你从复习材料直接跳到刷题网站。

```
你的参考材料（课本 / 讲义 / 复习提纲）
  → 阶段一：AI 自动分析材料、按你的要求出题、输出标准格式的 Markdown 题集
  → 阶段二：调用模板化 build.py，自动生成纯前端刷题网站（index.html）
```

最终产物是一个**单页 HTML 文件**，双击即可使用，不需要服务器、不需要数据库、不需要注册账号、不需要写任何代码。

除了期末复习，老师、助教、培训师也可以用这个 Skill 快速为自己的学生生成题库和练习网站。如果你只需要其中某一个阶段（比如只出题不做网站，或者已有题库只想建站），也完全支持——分批交代即可。

## 技术架构

### 总体设计

本 Skill 是一条两阶段的流水线，两个阶段共享同一份「标准 Markdown 题库」作为数据契约：

```
┌─────────────┐   阶段一       ┌──────────────┐   阶段二       ┌─────────────┐
│  参考材料     │ ──────────→  │  Markdown 题库 │ ──────────→  │  单页刷题网站 │
│ 教材/讲义/提纲 │  AI 出题     │  (数据契约)    │  build.py     │  index.html │
└─────────────┘              └──────────────┘              └─────────────┘
```

- **阶段一 · 出题**：AI 读取参考材料，按收集到的需求（范围 / 题型 / 题量 / 风格）逐批生成题目，每批经用户复核，最终输出按章节分文件的标准 Markdown 题集。
- **阶段二 · 建站**：AI（或用户手动）调用 `build.py`，解析 Markdown 题集，将其编译为自包含的单页 HTML 刷题网站。

### 建站引擎（build.py）

| 项目 | 技术选型 |
|:-----|:-----|
| 运行环境 | Python 3（仅标准库：`os` / `re` / `json` / `hashlib` / `argparse`，**零第三方依赖**） |
| 前端产物 | 原生 HTML + CSS + JavaScript，**零框架、零 CDN 依赖** |
| 音效 | Web Audio API 纯代码合成（点击音、答对上升双音、答错低沉蜂鸣），无任何音频文件 |
| 数据持久化 | 浏览器 localStorage，按输出文件夹名隔离（多题库互不干扰） |
| 题目 ID | `q_` + 题干内容 md5 前 8 位，题目增删 / 调序不破坏用户已有进度 |
| 版本检测 | build.py 自动注入版本哈希，题库更新后页面顶部提示「题库已更新」 |
| KaTeX 支持 | `--katex` 参数开启公式渲染，KaTeX 脚本与 20 个 woff2 字体全部 base64 内联，保持离线单文件（题库含公式时使用） |
| 中文标点规范化 | 构建时把 `"` `'` 转为 `“”` `‘’`、`...` 转为 `……`、`--` 转为 `——`；英文撇号与反引号代码段保留；可用 `--no-smart-quotes` 关闭；不影响题目 ID 与刷题进度 |
| 知识点树状面板 | 按章节分组展开选择，章节顺序取自题库文件顺序，弹窗宽度 960px |
| 判断题答案兼容 | 答案写成 正确 / 正確 / 对 / 對 / 是 / ✔ / √ 或 错误 / 錯誤 / 错 / 錯 / 否 / ✘ / × 均可识别，「✘ 錯誤」这类混写同样支持 |
| 题库语体自适配 | 构建时自动统计繁简特征字，繁体题库显示「正確 / 錯誤」，简体题库显示「正确 / 错误」；判分与进度存储始终用同一套内部值，切换语体不影响已有进度 |
| 构建对账 | 输出「文件内题块 / 成功解析」两个真实数字；对不上时逐条列出题号、答案内容与题干开头，便于定位格式问题 |

### 数据契约：Markdown 题库格式

题目文件是普通 Markdown，三种题型均有标准标注，便于 AI 生成、人工审阅、随时修改：

题干、选项、解析、知识回溯四处均支持 Markdown 子集语法（表格、引用、列表、加粗、行内代码、代码块、上下标），另可用 `$…$` / `$$…$$` 书写公式（构建时需加 `--katex`）。不支持单星号 / 下划线斜体，以免误伤语言学的 `*构拟形式` 与 `_词素边界_`。

```markdown
### 第 1 题（单选题）

下列不属于语法单位的是（ ）

A. 语素
B. 词
C. **短语**
D. 句子

**答案**：C

**解析**：短语是由词组成的语法单位……（考察点说明）

**知识回溯**：第二节·语法单位
```

- **答案**：单选一个字母；不定项用 ` · ` 分隔多个字母（如 `B · C · D`）；判断填 `正确` / `错误`
- **知识回溯**：题目关联到教材知识点位置，是「知识点专项」模式的索引依据

## 安装

本 Skill 以**源码树**形式维护，压缩包是它的分发形态，**两者内容完全一致**。

### 方式一：从源码安装（推荐）

把本项目目录整个复制到客户端的 Skill 目录即可：

| 客户端 | Skill 目录 |
|:-------|:-----------|
| Cherry Studio | `…/CherryStudio/Data/Skills/quiz-complete/` |
| Claude Code | `~/.claude/skills/quiz-complete/` |

> ⚠️ 目录名须为 **`quiz-complete`**（与 `SKILL.md` 中 frontmatter 的 `name` 一致），
> 否则客户端无法识别此 Skill。
> 另须**连 `assets/` 目录一起复制**，否则 `--katex` 公式渲染会静默失效。

### 方式二：生成压缩包分发

需要把 Skill 发给他人时，用自带的打包脚本现场生成：

```bash
python pack.py                     # 输出到 _dist/quiz-complete.zip
python pack.py --output <路径>      # 指定输出位置
```

脚本会在打包前校验 `SKILL.md` 的 frontmatter 是否存在、`assets/` 是否齐全，
并在打包后复核，避免产出一个「装不上」的压缩包。

## 出题规范

### 出题流程

AI 在执行阶段一（出题）时，会按照以下步骤操作：

1. **材料摸底** — 检查参考材料是否已转为可读格式。若为 PDF 或扫描件，先调用 OCR 工具处理（需你确认）
2. **需求收集** — 逐一收集考察范围、题型、题量、解析风格、字体偏好、知识回溯粒度等；如有样题样本，在此阶段提供作为风格参考
3. **确认计划** — AI 给出题量分配方案（各章节各题型各多少题），你确认后执行
4. **逐批出题 + 复核** — 按知识点分组出题，每出一批暂停请你复核；可中途要求修改
5. **输出保存** — 按章节保存为独立的 `.md` 文件，格式严格遵循标准标注

### 干扰项质量标准

- 干扰项必须基于真实的、常见的错误理解（如古今义混淆、概念偷换等）
- 错误选项不能过于突兀，必须在形式上与正确选项一致，在语境中看似合理
- 不定项选择题尽量不设置四项全对
- 每个选项都有独立考察价值，无凑数选项

### 考法画像与命题质量机制

出题阶段内置四道质量机制，适用于任何科目：

- **运行时考法画像**：每个新项目根据材料结构、学习目标和样题，现场推导该项目用到的考法家族与比例，不依赖固定科目清单
- **样题风格提炼**：有真题 / 样题时，先提炼题型、设问、选项、干扰项与难度特征，确认后再正式出题
- **首轮校准**：大批量前先出不超过 10 道试水题，按用户反馈修正画像后再继续
- **内容级自查**：出完题检查答案唯一性、干扰项可排除性、考点贴合度、难度与术语准确性

## 建站规范

### 交互特性

- **答题卡抽屉**：题号网格展示已答 / 正确 / 错误 / 未答 / 收藏状态；学习模式只允许回看已答题，不允许跳题
- **题目顶栏两行布局**：第一行为题目类型居中 + 收藏按钮右端，第二行为题号左顶格 + 章节标签右顶格；类型标签的居中基于卡片本身，不受收藏按钮宽度影响
- **选项字母模块**：选项开头的 A/B/C/D 抽成独立圆角方块，正文单独成栏，长选项换行后与第一行正文左对齐（悬挂缩进）；字母在选中 / 答对 / 答错时跟随状态变色
- **知识点树状面板**：知识点专项按章节分组展开，章节行可折叠、可一键全选该章，弹窗宽度 960px（窄屏自动回落到 94vw）
- **中文标点规范化**：构建时自动把 `"` `'` 转为 `“”` `‘’`、`...` 转为 `……`、`--` 转为 `——`；英文撇号与反引号代码段保留原样
- **首页学习概览**：一行显示"已练 X / 共 Y 题 · 正确率 Z% · 错题 N 题"，统计口径为所有模式累计（每题取最近一次作答）
- **模式卡片数量徽标**：错题专项显示错题数（清空时显示"已清空"）、随机与生涯模式显示剩余题数、专题与知识点显示板块数与标签数
- **重练本轮错题**：完成页在答完一轮后若存在错题，出现"🔁 重练本轮错题（N）"按钮，一键把本轮错题再练一遍（复用错题专项的只读与不可跳题规则）
- **收藏与我的收藏**：题干星标 ⭐（快捷键 `F`）加入收藏；首页右上角的"我的收藏"小入口可查看作答情况与解析（只读回看）
- **随机模式 · 智能优先**：可选开关，按跨模式累计的作答统计加权抽题，优先练习薄弱知识点；支持排除标签与重置统计
- **考试模式**：不限时但全程计时；考试中只记录作答、不判分不显示解析；未答完不能交卷；交卷后展示正确率 / 用时 / 题量，并可进入只读复盘（你的答案 vs 正确答案 + 解析）
- 键盘快捷键：`Enter` 提交、`← →` 切换题目、`1-4` 选选项
- 连续答对 3 题以上显示 🔥 连对标记
- 所有按钮悬停放大（scale: 1.04）、点按回弹
- 提交答案后自动滚动到裁决区
- 答对 / 答错均展示确认条，配合弹跳动画
- 完成时撒纸屑庆祝动画 + 统计面板

### 六种刷题模式

默认六种全开（通过 `--modes` 参数可只启用部分）：

| 模式 | 标识 | 默认 | 说明 |
|:-----|:----|:----:|:-----|
| 📖 **专题模式** | `topic` | ✅ | 按板块分层选择，顺序刷题，退出自动保存进度 |
| 🎲 **随机模式** | `random` | ✅ | 从总题库随机抽题，永不重复，不保留进度；可选"智能优先"：按薄弱知识点加权抽题，题池耗尽时可重置进度 |
| 🎯 **生涯模式** | `career` | ✅ | 答对永久移除，答错进错题池，全部通关自动存档 |
| 📝 **错题专项** | `wrong` | ✅ | 错题池采用掌握制：任何模式答错入池、任何模式答对出池（考试交卷后同样生效）；进入该模式集中消灭当前错题 |
| 🏷️ **知识点专项** | `tag` | ✅ | 按「知识回溯」标签选择范围刷题，支持一次选择多个知识点（合并成一个练习队列） |
| 📋 **考试模拟** | `exam` | ✅ | 自定义题数；不限时但计时；考试中不判分、可自由跳题；未答完不可交卷；交卷后结算（正确率 / 用时 / 题量）并支持只读复盘 |

你可以在建站时指定只启用部分模式，未被启用的模式不会在网站中出现。

### 三种视觉风格

通过 `--style` 参数切换：

| 风格 | 参数值 | 特点 |
|:-----|:-------|:-----|
| 古朴宣纸风 | `宣纸`（默认） | 暖色调、宋体/黑体、纸纹径向渐变，适合文史类题库 |
| 瑞士国际主义 | `瑞士` | 纯白底色、无衬线字体、蓝色强调色，适合理工类题库 |
| 极简卡片风 | `卡片` | 圆角卡片、柔和阴影、多色块区分，通用风格 |

### CLI 参数说明

建站时 AI 会自动调用模板 build.py，你也可以手动执行：

```bash
python build.py \
  --input "题库路径" \
  --title "网站标题" \
  --output "输出目录"
```

全部参数：

| 参数 | 必填 | 说明 |
|:-----|:----|:------|
| `--input` | ✅ | 题库 Markdown 文件夹路径（含 .md 文件的目录，递归搜索子目录） |
| `--title` | ✅ | 网站标题 |
| `--output` | ✅ | 输出目录（生成的 index.html 保存到此） |
| `--modes` | | 启用的模式，逗号分隔（默认六种全开: `topic,random,career,wrong,tag,exam`） |
| `--style` | | 视觉风格（默认: `宣纸`，可选: `宣纸` / `瑞士` / `卡片`） |
| `--subtitle` | | 副标题，显示在首页标题下方 |
| `--katex` | | 启用 KaTeX 公式渲染（内联约 630 KB，保持离线单文件；题库含公式时使用） |
| `--custom-css` | | 自定义 CSS 变量覆盖（轻度定制配色，无需修改模板） |
| `--prefix` | | localStorage 存储前缀（通常自动生成，无需手动指定） |

## 自定义与维护

### 轻度定制（改配色、改字体）

不需要修改 build.py。在调用命令中加入 `--custom-css` 参数即可覆盖任意 CSS 变量：

```bash
python build.py \
  --input "题库路径" \
  --title "标题" \
  --output "输出目录" \
  --custom-css ":root { --accent: #e74c3c; --bg-page: #fdf6ec; }"
```

### 深度定制（改布局、加功能）

复制 skill 目录下的 `build.py` 到项目目录中，直接在副本上修改：

- 改 CSS 变量 → 自定义配色方案
- 改 `HTML_TEMPLATE` → 调整页面布局
- 改 JS 逻辑 → 增加或修改交互功能

模板中 90% 的代码是稳定的解析和交互逻辑，不需要动。只改需要改的部分即可。

## 更新题库

### 修改已有题目

直接编辑桌面上的 `.md` 文件（改答案、改错字、增删题目），然后告诉 AI：

> 「帮我重新生成一下刷题网站」

AI 会自动重新运行 build.py，生成新的 index.html。你也可以手动双击 `build.bat` 来完成同样的事。

### 追加新题目

有新章节或新材料时，告诉 AI：

> 「继续我上次的出题项目，追加第 11 章的内容」

AI 会读取之前保存在长期记忆中的项目状态，恢复你的偏好和进度，用新材料出题后追加到已有文件末尾，然后自动重建网站。

## 技术说明

| 项目 | 说明 |
|:-----|:------|
| 构建脚本 | Python 3（标准库，零第三方依赖） |
| 网站前端 | 原生 HTML + CSS + JavaScript（零框架依赖） |
| 题库格式 | Markdown（题型标注清晰，便于人工审阅和编辑） |
| 题目 ID | 基于题干内容哈希生成（`q_` + md5 前 8 位），增删调序不影响已有进度 |
| 版本检测 | build.py 自动注入版本哈希，题库更新时页面顶部提示「题库已更新」 |
| 数据持久化 | 浏览器 localStorage（按输出文件夹名隔离，多题库互不干扰） |
| 音效 | Web Audio API（零音频文件，纯代码合成） |
| 输出产物 | 单页 HTML（约 300–600 KB，双击可用，可部署到 GitHub Pages） |
