# 项目状态模板

> 本文件用于**跨会话工作**时的状态保存：把项目进展写入 FACT.md，下次会话即可恢复。
> 以下是 FACT.md 的**标准模板**，复制后按实际情况填写（`XXX` 处替换为真实值）。

---

## FACT.md 模板

```markdown
# 出题工作状态

## 项目信息
- 项目名称：XXX
- 输出根目录：XXX
- 最后更新时间：YYYY-MM-DD HH:MM

## 用户偏好
- 字体：繁体/简体
- 知识回溯粒度：章级
- 建站偏好：六种模式全开/简约风格

## 项目考法画像
- 考法家族与比例：如 记忆辨析 60% / 材料分析 40%
- 题目级标签要点：
- 难度基线：
- 样题风格要点：（有样题时填写）
- 首轮校准结论：

## 完成进度
- 阶段一（出题）：模块 N/N，共 N 题
- 阶段二（建站）：已构建 / 未开始

## 待办事项
- [ ] 待补充内容
```

---

## 使用时机

| 操作 | 用途 | 时机 |
|:-----|:------|:------|
| 更新 FACT.md | 记录项目全局状态（已完成、待办、用户偏好、路径等） | **每次会话结束前**执行一次 |
| 追加 JOURNAL.jsonl | 记录逐次操作日志（完成了哪些文件、增减多少题） | **每次出题动作完成后**执行 |

## 会话恢复流程

```
新会话开始
  → 读 FACT.md（如已知项目名称），或用记忆检索「出题工作记忆」
  → 恢复用户偏好、已完成进度、待办列表
  → 继续工作
```
