# 建站指南

> 返回主流程：[`SKILL.md`](../SKILL.md)

仅在用户要求生成刷题网站时读取。建站复用模板 `build.py`，不重新编写构建器。

## 题库格式

只解析以下题型：

| 题型 | 选项 | 答案 |
|:--|:--|:--|
| 单选 | A/B/C/D | `**答案**：C` |
| 不定项 | A/B/C/D | `**答案**：A · B · D` |
| 判断 | 无 | `正确` / `错误`，兼容 `正確/錯誤/对/否/√/×` 等 |

## 专题分级

题库可在 H1 后声明：

```markdown
**板塊**：常用詞
**順序**：1
**教材依據**：……
```

- `**板塊**` 为一级目录；缺省回退到文件目录名。
- `**順序**` 为组内整数排序；缺省排在显式编号之后。
- 没有任何文件声明板块时，保持原平铺列表。
- H1 章节名是 localStorage 进度键，改名会丢进度。

## 富文本与公式

题干、选项、解析和知识回溯支持表格、引用、列表、加粗、行内代码、代码块、
上下标和段内换行。

- 不支持单星号/下划线斜体。
- 题目之间的分隔必须是独立成行的 `---`。
- 公式需显式加 `--katex`。
- KaTeX 会增加约 630 KB，但仍保持单文件离线。
- 内容先转义再渲染，题库中的 HTML 标签显示为文本。
- 自动把直引号成对转换为中文引号，`...` 转为 `……`，`--` 转为 `——`；
  英文撇号和反引号代码段保留。可用 `--no-smart-quotes` 关闭。

## 刷题模式

默认六种全开：

| 模式 | 作用 |
|:--|:--|
| 专题 | 按板块和章节顺序刷题，退出保存进度 |
| 随机 | 随机抽题、不重复、不保留进度 |
| 生涯 | 答对移除，答错入错题池，通关存档 |
| 错题专项 | 任何模式答错入池、答对出池 |
| 知识点专项 | 按知识回溯标签多选合并练习 |
| 考试模拟 | 固定题量、计时、交卷后结算与复盘 |

## 视觉风格

- `宣纸`：暖色、宋体、纸纹，适合文史题库，默认。
- `瑞士`：白底、无衬线、单一强调色。
- `卡片`：圆角、柔和阴影、多色块。

## 构建命令

Windows PowerShell：

```powershell
py -3 "<skill_dir>\build.py" `
  --input "<工作目录>\题库" `
  --title "网站标题" `
  --output "<工作目录>\网站" `
  --modes topic,random,career,wrong,tag,exam `
  --style 宣纸
```

macOS / Linux：

```bash
python3 "<skill_dir>/build.py" \
  --input "<工作目录>/题库" \
  --title "网站标题" \
  --output "<工作目录>/网站" \
  --modes topic,random,career,wrong,tag,exam \
  --style 宣纸
```

主要参数：`--subtitle`、`--katex`、`--allow-missing-katex`、`--custom-css`、
`--no-balance`、`--no-audit`、`--strict-audit`。

| 参数 | 说明 |
|:--|:--|
| `--input` | 题库 Markdown 文件夹，必填 |
| `--title` | 网站标题，必填 |
| `--output` | 输出目录，必填 |
| `--modes` | 逗号分隔；默认 `topic,random,career,wrong,tag,exam` |
| `--style` | `宣纸` / `瑞士` / `卡片`，默认宣纸 |
| `--subtitle` | 副标题 |
| `--katex` | 启用 KaTeX |
| `--allow-missing-katex` | 允许资源缺失时显式降级 |
| `--custom-css` | 覆盖 CSS 变量，无需 fork 模板 |
| `--prefix` | localStorage 前缀，通常自动生成 |
| `--no-balance` | 跳过答案均衡 |
| `--no-audit` | 跳过质量审计 |
| `--strict-audit` | 任一审计告警即失败 |

## 构建失败

以下情况返回非零退出码，且不生成或覆盖 `index.html`：

- 输入目录不存在或不是文件夹；
- 目录中没有 Markdown；
- Markdown 中没有题块；
- 任意题块解析失败；
- 没有成功解析任何题目。

使用 `--katex` 但资源不完整时同样失败；只有用户明确同意时才能添加
`--allow-missing-katex` 生成无公式页面。

## 构建期自动处理

- 答案位置均衡，含位置敏感选项或字母引用的题跳过重排；
- 繁简体界面文案自适配；
- 中文标点规范化；
- 质量审计；`--strict-audit` 可将告警升级为失败；
- 题目 ID 和版本哈希注入。

模板覆盖绝大多数布局和交互需求。若确有特殊布局或额外功能，可复制模板 `build.py`
到项目后修改 HTML/CSS/JS；90% 的稳定代码不需要动。

## 输出与更新

正式产物只有：

```text
<工作目录>/
├── REQUIREMENTS.md
├── 题库/
└── 网站/
    └── index.html
```

不要自动生成 `build.bat` 或项目 README。需要项目说明时由用户另行要求。
用户修改题库后，Agent 直接重新运行 `build.py`，不追问“要不要重建”。

## 建站复核

- 构建退出码为 0，所有题块解析成功；
- 首页题数与需求一致，六种或指定模式按钮存在且可点击；
- 单选、不定项、判断都可选择、提交并显示正确答案与解析；
- 题型 Badge 清晰显示，完成页、答题卡和模式入口正常；
- 所有按钮 hover 放大，动画不阻塞悬停；
- 题干、选项、解析、知识回溯中的 Markdown 子集渲染正确；
- 含公式时未残留 `$…$` 原文，页面无 JS 控制台错误；
- `VERSION_HASH` 已注入，生成页面可离线双击打开；
- 复核结果写入 `REQUIREMENTS.md`。
