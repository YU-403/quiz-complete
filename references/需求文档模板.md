# REQUIREMENTS.md 模板

> 本文件用于初始化用户工作目录中的 `REQUIREMENTS.md`。
> 它是项目唯一的需求、决策、验收和跨会话恢复来源，不依赖宿主长期记忆
> 或其他本地 Agent 私有状态文件。

## 使用规则

1. 用户确认工作目录后，立即复制下面的模板创建 `REQUIREMENTS.md`。
2. 每次只问一个问题；收到回答后先更新文档，再问下一题。
3. 用户接受默认值时，来源记作“默认值”；用户主动回答时，来源记作“用户”。
4. 没有默认值的项目不得自动填写，状态保持“待确认”。
5. 用户修改决定时保留旧记录，并追加新版本和变更原因。
6. 需求冻结、每批出题后和最终交付前都读取本文件复核。
7. 继续已有项目时，先读取本文件，不依赖旧对话或宿主记忆。
